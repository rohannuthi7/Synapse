Synapse
=======

A graduate hardware study on one DE10-Nano. The neuron model is settled. The open question is which delivery microarchitecture keeps a spiking network correct when the fabric cannot service every spike in time.

Hypothesis. With one leaky-integrate-and-fire datapath per core, a fixed block-RAM budget, and a fixed number of clocks per timestep, a placement of neurons that cuts cross-core spikes preserves accuracy farther up the firing-rate curve than a smarter overload policy does. Past the rate where the single datapath itself saturates, placement and policy converge, because the core runs out of arithmetic before it runs out of routing.

That sentence is the project. It can be false. The writeup reports the crossover if it exists and reports that it does not if the curves never separate.


Position
--------

Digital neuromorphic chips already time-multiplex. TrueNorth and Loihi emulate many logical neurons on fewer physical updates, and they move spikes as address events. This design does not invent that pattern. It holds the silicon budget still and varies three choices those chips make differently: where neurons sit, which late spike is kept, and how decay is applied so idle neurons are not visited.

The deliverable is an ablation on one chip, not a new biological learning rule and not a tape-out. Quartus area numbers, cycle counters, and agreement with an infinite-budget reference are the evidence.


Fixed budget
------------

These stay constant across every point in the study. Changing them is a different experiment.

    4 cores
    1 physical LIF datapath per core
    the same on-chip RAM budget for synaptic records and neuron state
    the same clock count per timestep
    int8 weights, integer membrane, the same threshold, reset, and refractory

Logical population is what scales: 256, 1024, and 4096 neurons, sparse, on the order of ten synapses each. If 4096 does not fit in the Cyclone V block RAM, the largest population that fits is the top of the sweep, and the overflow is a reported limit.

The physical datapath is a single pipeline that reads one neuron's state from block RAM, applies the spikes due this tick, writes the state back, and moves on. One hundred logical neurons on a core are one hundred turns of that pipeline, not one hundred copies of the adder.


Lazy leak
---------

A leak applied to every logical neuron every timestep forces the pipeline to visit everyone, which erases the event rule and makes the hypothesis trivial. Decay is lazy.

Each neuron stores v and the timestep when v was last written. On the next touch at time t:

    gap = t - last_t
    v = decay_gap(v)
    last_t = t
    then add the weights delivered at time t

decay_gap is a fixed-point approximation of repeated decay, built from shifts, exact against the Python model for every gap the sweep can produce. A neuron whose membrane only shrinks cannot cross threshold because of leak alone, so untouched neurons do not need a visit. A visit happens because a spike is delivered or because a delayed spike comes due.

The approximation is part of the work. A decay that matches Python for a gap of 1 and drifts at a gap of 30 will silently change who fires. The testbench sweeps gaps.


Placement
---------

The synapse graph is partitioned onto the four cores before a run.

    Random. Neurons are dealt out round-robin. This is the control.
    Cut. A greedy partitioner groups neurons that share synapses onto the same core, then balances population so one core does not inherit the pipeline.

The partitioner runs in software on the ARM or offline. It writes a core id per neuron and rebuilds each core's sparse list so local targets stay local and remote targets become packets.

Measured for each placement, at each population and each firing rate:

    fraction of synapses that cross cores
    packets injected
    pipeline turns used
    undelivered work at the timestep boundary
    agreement with the infinite-budget reference

The cut is not allowed to change weights or delays. If accuracy moves, it moves because traffic moved.


Overload policy
----------------

When the clock budget hits zero, unfinished deliveries still exist. Three policies, same placement, same budget:

    Defer. Leftover packets stay queued and apply on a later timestep. Delivery time slips. STDP windows slip with them.
    Drop-oldest. The oldest unfinished packet is discarded. A counter records the loss.
    Drop-smallest. Among unfinished packets, the one with the smallest absolute weight is discarded. Large synapses are kept.

All three are implemented in the same queue. The policy is a mode bit. A policy that is really "defer" with a different name will show identical undelivered counts and identical outputs, and that bug is visible in the table.

The dense reference does not use these policies. It applies every due synapse at a fixed cost and defines correct spikes when the budget is not the constraint.


Correctness oracle
-------------------

Python holds the infinite-budget network: same lists, same delays, same lazy decay, same rectangular STDP on delivery times. Wide-open hardware mode must match its spike times and its final weights. Any mismatch there is a bug, and no accuracy number from that bitstream is usable.

Tight-budget runs are allowed to diverge. Divergence is reported as spike-time distance and, on the classifier, as class accuracy against the labels, not against a story about why the chip "still understood."


Task and sweep
--------------

Unit tests before any sweep: one delayed spike, a lazy leak over a long gap, a local synapse, a remote synapse, each overload policy on a burst that is one packet too long, STDP inside the window and outside it, a partition that moves one edge from remote to local.

Then the grid:

    population: three sizes, up to what block RAM holds
    rate: sparse Poisson through a burst that saturates the pipeline
    placement: random, cut
    policy: defer, drop-oldest, drop-smallest
    budget: the fixed study budget, plus the wide-open bug-check

The classifier is small and offline-trained. Output class comes from spike counts of a designated set of neurons. Training is a tool. The hardware result is accuracy under the grid above.

STDP stays on during the sweep, using delivery time. A second sweep with STDP off separates "the router dropped spikes" from "learning walked away because delivery times moved." Both tables are required. One of them is expected to be the less flattering one.


What the result has to contain
------------------------------

A table of cross-core fraction, pipeline occupancy, undelivered packets, and accuracy for every cell of the grid.

The firing rate, if any, where cut-plus-defer beats random-plus-drop-smallest by a margin larger than run-to-run variation. Poisson inputs are repeated for several seeds.

The firing rate, if any, where all six hardware combinations sit on top of each other because the pipeline is full. If the curves never meet, the hypothesis is wrong and the plot is still the result.

Quartus counts for ALMs, block RAM, and DSP blocks of the final configuration. An extra datapath built "to make the demo smoother" is a changed budget and voids the comparison.

Counters on the board, not a cycle estimate from a slide: read-enable lows, packets sent, packets dropped, packets deferred, pipeline turns, timesteps that ended with work left.


What this is not
----------------

A new neuron model. An analog membrane. A memristor array. A claim that a few thousand multiplexed neurons are a brain. They are a scheduled pipeline with a packet queue.

Graduate, here, means the outcome is an answer to the hypothesis under a budget you refused to raise. A demo that only shows the sparse, wide-open corner is the undergraduate version of this same chip.
